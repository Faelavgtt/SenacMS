# 🚀 Técnico em Desenvolvimento de Sistemas - SENAC MS

## 📖 Sobre Este Repositório

Bem-vindo ao meu portfólio de aprendizagem! Este repositório centraliza todos os projetos, exercícios e conhecimentos que adquiri durante o **Curso Técnico em Desenvolvimento de Sistemas** no **SENAC MS**, uma jornada de 1 ano e meio.
